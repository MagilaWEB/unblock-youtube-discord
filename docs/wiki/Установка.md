# 📥 Установка

## Системные требования

| Что | Требование |
|---|---|
| ОС | Windows 10/11, 64-bit |
| Права | Администраторские |
| Диск | ~100 МБ свободного места |
| Интернет | нужен установщику — он качает сборку с GitHub |

Приложение запускается с правами администратора: движок обхода ставит службы Windows, грузит драйвер WinDivert и меняет системный DNS. `engine.exe` умеет самозапрашивать повышение прав через UAC, но службы без админа не поднять, так что запускайте ярлык от имени администратора.

## Установка через `unblock-setup.exe`

1. Скачайте `unblock-setup.exe` из [последнего релиза](https://github.com/MagilaWEB/unblock-youtube-discord/releases).
2. Запустите — установщик сам скачает актуальную сборку (`unblock.7z`) с GitHub и распакует её. Это займёт меньше минуты, на экране видно прогресс и скорость.
3. Выберите папку установки (по умолчанию `C:\unblock`) и завершите мастер.
4. Запустите Unblock ярлыком из меню «Пуск». Галочка «ярлык на рабочем столе» есть в установщике, по умолчанию снята.

Установщик требует прав администратора и сам спросит их через UAC. Перед заменой файлов он останавливает службы `zapret1`, `zapret2`, `zapret2_helper`, `unblock_dns` и `TgWsProxy`, а при обновлении поверх прошлой версии заменяет только код и ресурсы — `user/` и `logs/` остаются на месте.

Установщик онлайн и маленький: сам себя payload-ом не тащит. Если скачать не удалось, он покажет ошибку и не тронет систему — можно нажать «Далее» и повторить. Если интернета нет вообще, берите portable-вариант: `unblock.7z` не требует загрузки при установке.

## Portable-вариант `unblock.7z`

В релизе рядом лежит `unblock.7z` — распакуйте его в корень диска (`C:\unblock\` или `D:\unblock\`) и запустите `bin\engine.exe` от имени администратора. Внутри архива лежит папка `unblock`, её содержимое и есть приложение.

Портативно можно всё то же, кроме записи в «Программы и компоненты», ярлыков и автоматической чистки папки при удалении: файлы придётся снести руками. Встроенные обновления работают и здесь — `user/` и `logs/` при обновлении сохраняются.

> Путь установки не должен содержать пробелов и кириллицы. Это же условие для портативной распаковки — иначе часть утилит, участвующих в обходе, заведётся с ошибкой.

## Что лежит после установки

```
unblock\
├─ bin\           исполняемые файлы приложения: engine.exe, zapret_helper.exe,
│                 unblock_dns.exe, unblock_update.exe, AdguardDns64.dll, 7za.dll
├─ binaries\      движки и данные обхода: winws2.exe, winws.exe, cygwin1.dll,
│                 SvcHost.exe, tg-ws-proxy.exe, WinDivert.dll, WinDivert64.sys,
│                 lua\ (скрипты zapret + unblock), fake\ (бинарные фейк-блобы)
├─ configs\       стратегии и списки: strategy\<поколение>\, strategy_zapret1\<поколение>\,
│                 blacklist\, ip-set\, domain_test\, dns_hosts\, *.config
├─ ui\            интерфейс: main.html, css\, scripts\, text\ (RU/US)
├─ user\          ваши настройки (создаётся при первом запуске)
├─ logs\          журналы
├─ LICENSE.txt
└─ README.md
```

`user/` — это то, что переживает обновления: `setting.config` (настройки интерфейса и обхода), папки `blacklist/` и `ip-set/` (эффективные списки), `domains_exclude.list` и `ip-exclude.list`, а также файлы DNS-прокси `dns_proxy.conf`, `dns_proxy.adapters` (бэкап адаптеров) и `dns_proxy.log`.

`logs/` — журналы: `log.txt` (общий лог приложения), `strategy.args.txt` (аргументы, с которыми реально запущен движок), `service-report.txt` (отчёт диагностики последнего неудачного старта службы, подробнее — [Отчёт диагностики](Отчёт-диагностики)). Логи движков лежат рядом с их бинарниками в `binaries/` (`winws2.exe.log`) и в `bin/` (`zapret_helper.exe.log`).

## 🔄 Встроенные обновления

Новые версии ставятся из приложения: Unblock сам проверяет `releases/latest` на GitHub и предлагает обновление. При согласии он скачивает `unblock.7z`, распаковывает его во временную папку и запускает оттуда отдельный помощник `unblock_update.exe` — тот дожидается закрытия старого движка, чистит управляемые каталоги (`bin/`, `binaries/`, `ui/`) и копирует новую сборку, не трогая `user/` и `logs/`, после чего запускает свежий `bin\engine.exe`. Прогресс пишется в `%TEMP%\unblock_update.log`.

## 🗑️ Удаление

Через «Программы и компоненты» Windows. Деинсталлятор зовёт `bin\engine.exe --uninstall`, и приложение снимает за собой то, о чём знает только оно:

- выключает DNS-функцию — останавливает `unblock_dns` и убирает hosts-пины, возвращая адаптерам прежний DNS;
- выключает Telegram-прокси;
- удаляет свои службы (`zapret1`, `zapret2`, `zapret2_helper`), драйвер WinDivert и настройки помощника.

Дополнительно установщик страхуется списком `sc stop`/`sc delete` для всех служб и возвращает системный параметр TCP-таймстампов (`netsh interface tcp set global timestamps=disabled`) — его приложение включало, только если стратегия этого требовала.

Если папку удалить руками, не запуская деинсталлятор, службы и драйвер останутся в системе — их придётся снять вручную (`sc delete <имя>`).
