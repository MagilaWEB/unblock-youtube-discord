# 🚀 Unblock: Обход блокировок YouTube, Discord, Instagram и других сервисов

![GitHub Stars](https://img.shields.io/github/stars/MagilaWEB/unblock-youtube-discord?style=for-the-badge&logo=github&color=yellow)

![Windows Version](https://img.shields.io/badge/Windows-10%2F11-0078D6?style=for-the-badge&logo=windows&logoColor=white)

**Unblock** — программа для Windows, которая обходит DPI-блокировки и региональные ограничения. Разблокирует YouTube, Discord, Instagram, X и другие сервисы, заблокированные провайдером или РКН. Работает на базе движка **zapret2** с собственными модифицированными алгоритмами обхода: адаптивным перебором стратегий и фоновым помощником `zapret-helper`.

## ✨ Возможности

### 🛡️ Многоуровневый обход блокировок
| Тип блокировки | Метод обхода | Эффективность |
|----------------|--------------|---------------|
| **DPI-блокировки** | Фрагментация и маскировка пакетов | Высокая |
| **DNS-фильтрация** | Локальное сопоставление IP к Domain | Полная |
| **Региональные ограничения** | Подмена геолокации через local DNS ([GeoHide DNS](https://dns.geohide.ru:8443)) | Средняя-Высокая |

### 🎯 Ключевые особенности
- **Умный UI**: Нативный интерфейс на базе WebView2 ([saucer](https://github.com/saucer/saucer)) с интуитивным управлением
- **Автоподбор конфигураций**: Автоматический выбор оптимальных настроек
- **Готовые профили**: Предустановленные конфигурации для быстрого запуска
- **Фильтрация по доменам**: Поддержка .com, .net, .org и других TLD
- **Локальный прокси-сервер**: TgWsProxy от Flowseal
- **Многопоточность**: Высокая производительность на С++
- **Автономная сборка**: библиотеки вшиты в исполняемые файлы — минимум файлов в комплекте
- **Открытый код**: Полная прозрачность работы

### 🧠 Адаптивная стратегия обхода (auto_strategy)
- **Прямой трафик первым**: каждое новое подключение сначала пробует идти без обхода (`direct`)
- **Последовательный перебор**: при сбое происходит переключение на `strategy_1`, `strategy_2`, ... `strategy_N`
- **Детекция блокировки**: RST, обрыв на 16 КБ (DPI), принудительные редиректы, ретрансмиссии и UDP-стагнация
- **Подтверждение через zapret-helper**: если для хоста получен `FAIL`, текущая стратегия бракуется и происходит ротация
- **Понятные логи**: в логах выводится `direct` или `strategy_N` вместо безликого номера

### 🛠️ Фоновый помощник zapret-helper
- **Сервис `zapret2_helper`**: отдельный процесс `zapret_helper.exe`, запускается вместе с Zapret
- **Список хостов по UDP**: при старте unblock отправляет хосты из `configs/domain_test` на порт `10000`
- **Проверка доступности**: каждый хост проверяется через curl (HEAD с fallback на GET), результат `OK`/`FAIL` уходит обратно
- **Интеграция с auto_strategy**: профиль `zcheck` в winws перехватывает ответы и передаёт их в адаптивный перебор стратегий

## 📥 Установка

### Системные требования
- **ОС**: Windows 10/11 (64-bit)
- **Права**: Администраторские права
- **Диск**: 100 МБ свободного места

### Шаги установки:
1. **Скачайте** последний [релиз](https://github.com/MagilaWEB/unblock-youtube-discord/releases)
2. **Распакуйте** архив в корень диска (`C:\unblock\` или `D:\unblock\`)
3. **Запустите** `engine.exe` от имени администратора

> ⚠️ **ВАЖНО**: Не распаковывайте на Рабочий стол! Это может вызвать проблемы с путями.

## ⚠️ Решение проблем

### 🔴 Антивирусные предупреждения
WinDivert может вызывать ложные срабатывания антивирусов. Это легитимный драйвер для работы с сетевым трафиком. Добавьте в исключение, отключать антивирус не обязательно.

### 🔴 Конфликты с VPN
- Отключите **TUN режим** в настройках VPN
- Проверьте, не блокирует ли VPN локальные подключения

### 🔴 Обход не работает
**Проверьте:**
1. ✅ Путь без пробелов и кириллицы
2. ✅ Установка в корень диска (не на Рабочий стол)
3. ✅ Отключен брандмауэр для тестирования
4. ✅ Правильно выбран режим работы

**Если проблема осталась:**
1. Возьмите одну из конфигураций в папке `configs/strategy`
2. Создайте свой профиль на его основе
3. Если что-то не понятно обратитесь в [обсуждения](https://github.com/MagilaWEB/unblock-youtube-discord/discussions)

### 🔴 Создание собственных конфигураций
Если стандартные профили не работают, изучите документацию:

Zapret: https://github.com/bol-van/zapret2/blob/master/docs/readme.md

Создайте файл в папке `configs/strategy` и поделитесь рабочим профилем в обсуждениях.

## 🔒 Безопасность

### Проверка файлов
Все исполняемые файлы взяты из проверенных источников:
- [zapret2](https://github.com/bol-van/zapret2)
- [TgWsProxy](https://github.com/Flowseal/tg-ws-proxy) Собран в режим работы через консоль, в оригинальном репозитории такого .exe нет.

Вы можете проверить контрольные суммы для подтверждения подлинности.

### Открытый код
Проект основан на открытом исходном коде:
- Основной движок: [zapret2](https://github.com/bol-van/zapret2)
- Прокси телеграмм: [TgWsProxy](https://github.com/Flowseal/tg-ws-proxy)

Unblock использует движок **zapret2**, но с **модифицированными алгоритмами обхода** от unblock: собственные Lua-скрипты (`auto_strategy`, `zcheck`), адаптивный перебор стратегий, фоновый помощник `zapret-helper`. Если бы не автор zapret2 — [bol-van](https://github.com/bol-van), этого проекта, возможно, не существовало бы.
